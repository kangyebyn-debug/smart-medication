# 로컬에서 프론트·백엔드 실행하기

- 확인일: 2026.11.18 (Git Bash 기준, 저장소 루트: `D:\Project_KYB\smart-medication`)
- `backend/.env`는 이미 `SERVICE_KEY`가 채워져 있는 상태로 확인됨 (새로 받을 필요 없음)
- 이 안내와 아래 체크리스트는 현재 로컬 코드 기준입니다. Vercel·Render에 최신 변경이 반영되었는지는 확인되지 않았습니다.

---

## 1. 백엔드 (FastAPI)

```bash
cd backend
source .venv/Scripts/activate      # 이미 .venv 폴더 있음 (처음 받은 거라면 아래 "처음 세팅" 참고)
uvicorn app.main:app --reload --port 8000
```

- 실행되면 http://localhost:8000/health 에서 `{"status": "ok"}` 확인
- API 문서(Swagger UI): http://localhost:8000/docs

**처음 세팅하거나 `.venv`가 없을 때:**
```bash
cd backend
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
test -f .env || cp .env.example .env  # .env가 없을 때만 복사하고 SERVICE_KEY 값 채워넣기
```

## 2. 프론트엔드 (React + Vite)

```bash
cd frontend
npm install              # package.json 바뀐 뒤 처음 한 번, 또는 node_modules 없을 때
npm run dev
```

- 터미널에 뜨는 주소(보통 http://localhost:5173)로 접속
- 프론트 코드의 기본 API 주소는 `http://localhost:8000`이므로 위 1번 백엔드가 떠 있으면 별도 설정 없이 연결됨. 다른 주소를 쓸 때만 `frontend/.env.local`에 `VITE_API_URL`을 설정

## 3. 둘 다 띄우기

Git Bash 창 2개 사용:
- 창 1: 위 1번(백엔드) 실행하고 그대로 켜둠
- 창 2: 위 2번(프론트) 실행

백엔드 먼저 띄운 뒤 프론트를 켜는 순서를 권장 (프론트가 켜질 때 바로 API를 찌르지는 않지만, 검색을 눌렀을 때 백엔드가 없으면 에러만 남).

## 4. 확인 체크리스트 (Codex 작업물 QA용)

- [ ] 첫 랜딩에서 약 이름 입력 → 검색 화면으로 이동하며 입력한 검색어로 결과가 뜨는지
- [ ] 랜딩의 기능 카드와 앱의 사이드바에서 검색·병용금기 확인·나의 약 각 화면으로 이동하는지
- [ ] 약품 검색: "타이레놀" 등 검색 → 결과 클릭 → 이미지·효능·용법·4종 금기 탭이 뜨는지
- [ ] 병용금기 확인: 두 약 선택 후 "병용금기 확인하기" → 조회 범위의 결과가 표시되는지
- [ ] 나의 약: 등록/삭제와 "전체 병용금기 확인하기" 일괄 조회가 동작하고, 이 브라우저에만 저장된다는 안내가 보이는지
- [ ] 백엔드를 잠깐 끈 상태에서 검색 → 조회 실패 메시지와 "다시 검색" 버튼이 뜨는지. 백엔드를 켠 뒤 같은 검색어로 다시 시도되는지
- [ ] 정상 응답이 검색 결과 0건일 때는 조회 실패 메시지가 아닌 "일치하는 약품이 없습니다" 안내가 뜨는지
