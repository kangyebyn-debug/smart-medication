## 1. 확정된 방향

- **진입**: 로그인 전 단일 랜딩 홈 1장 (`Landing`) — 구글 메인화면처럼 넓은 영역에 검색/질문창 하나만 두는 미니멀 히어로
- **전환**: 랜딩에서 기능 카드를 클릭하면 **B안(사이드바 상시 내비게이션)** 앱 화면으로 전환
- **베이스**: 화면 수가 많아질수록(약 상세, 복약질문AI 전체화면, 나의 약, RAG 관리자 등) 지속형 사이드바가 다중 화면 내비게이션에 구조적으로 유리하다고 판단해 **B를 앱 전체의 베이스**로 채택
- A안(카드형 대시보드), C안(AI 챗 분할 히어로)은 최종 채택되지 않았으나, 랜딩 1페이지 안에서 각각의 모티프(A=미니멀 검색 히어로, C=다크 설명 패널+챗 미리보기)를 부분적으로 차용함

타이포그래피: 나눔바른고딕(기본 `NanumBarunGothic`, 강조 `NanumBarunGothicBold`)을 네이버 공식 웹폰트 CSS로 불러온다. 본문 설명·안내 문구는 최소 16px로 표시하고, 배지·짧은 라벨·보조 캡션은 용도에 맞게 더 작게 쓸 수 있다.

## 3. 반응형 설계 원칙

- 모든 화면은 **풀블리드(배경 전체 폭) + 콘텐츠 max-width 컨테이너** 조합으로 구성 — 화면 한가운데에 작게 뜨지 않도록 함
- 데스크톱 와이드 화면에서 콘텐츠가 비어 보이지 않도록, 단일 좁은 컬럼 대신 **보조 패널(빠른 질문, 근거 자료, 관련 약 등)을 측면에 배치**해 폭을 실질적으로 활용
- 레이아웃은 `flex-wrap`과 `grid-template-columns: repeat(auto-fit, minmax(...,1fr))`로 구성해 좁은 화면에서 자동으로 세로 스택(오버플로우 없이)
- 사이드바(B안 베이스)는 `flex: 0 0 260px`로 고정, 메인 콘텐츠는 `flex: 999 1 560px`로 나머지 폭을 모두 차지

### 4-1. 아직 전용 화면이 없는 항목

- "약품 검색", "병용금기 확인", "나의 약"은 사이드바 메뉴 항목으로는 존재하지만, 전용 화면은 아직 그리지 않았고 현재는 모두 `DesignB`(앱 홈)로 연결해 둠. 실제 개발 전에 각각 전용 화면 설계가 필요.

위 항목은 디자인 시안 캔버스의 당시 상태다. 2026.11.18 로컬 프론트 코드에는 약품 검색(`SearchPage`), 병용금기 확인(`InteractionPage`), 나의 약(`MyDrugsPage`) 전용 화면이 구현되어 있다. 복약 질문 AI 전체화면과 RAG 관리자는 아직 구현되지 않았다.

## 5. 랜딩 → B 내비게이션 매핑

랜딩의 기능 카드를 클릭하면 B안의 사이드바에서 같은 메뉴를 선택했을 때와 동일한 화면으로 이동하도록 설계함.

아래 표의 `DesignB` 임시 연결은 시안 캔버스 기준이다. 현재 로컬 구현에서는 랜딩 카드와 사이드바가 각각 같은 약품 검색·병용금기 확인·나의 약 화면으로 이동한다. 복약 질문 AI는 "준비 중"으로 안내한다.

| 랜딩 카드 | 이동 화면 | B 사이드바 동일 항목 |
|---|---|---|
| 약품 검색 | `DesignB` | 약품 검색 (전용 화면 미완성으로 임시 연결) |
| 병용금기 확인 | `DesignB` | 병용금기 확인 (〃) |
| 복약 질문 AI (메인 기능) | `B-Chat` | 복약 질문 AI |
| 나의 약 | `DesignB` | 나의 약 (〃) |

## 6. 컴포넌트 규칙

- **버튼**: 주요 행동(primary) = 녹색 배경 + 흰 글씨, 둥근 모서리 9px; 보조 행동(secondary) = 흰 배경 + 회색 테두리
- **카드**: 테두리 1px `#E4EAE7`, 모서리 14~16px, 배경 `#FBFDFC`; 메인 기능 강조 카드는 2px 녹색 테두리 + "메인 기능" 배지
- **채팅 버블**: 사용자 발화 = 녹색 배경 + 우측 정렬, AI 응답 = 연녹색 회색톤 배경 + 좌측 정렬, 모서리 중 한쪽만 각지게(말풍선 꼬리 효과)
- **금기 배지**: 병용금기(적색), 임부금기·노인주의(황색), 연령금기(중립 회색) — 색으로 위험도 구분
- **아이콘**: 인라인 stroke SVG, 이모지 사용 안 함
